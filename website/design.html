Design of Flavour

Flavour is a single-page app framework for Java and JVM languages.

It takes classes, templates, and resources as input, and outputs a JavaScript translation implementing the specified behavior. The output is capable of running in any modern web browser without any plugins or extensions.

Flavour is built on top of TeaVM. TeaVM provides the translation of Java class files (JVM bytecode) to JavaScript. All the HTML templates (and specially-handled resource files) are bundled into the single classes.js file that is loaded by the first page of a TeaVM application. Static files recognized by the browser (like CSS and images) are stored in the webapp folder and are loaded by the browser as they are referenced by the HTML.

Flavour provides numerous features that you would otherwise have to build yourself to make a complete single-page app:

  • Routing
  • Templates
  • Components
    • Provided
    • User-Defined
  • Expression Language
  • JSON Support
  • Transparent RESTFul Web Service Access

Modules

Flavour usese the maven build system. As with any efficient maven project, it is composed of multiple modules:
  • expr: The Flavour Expression Language
  • templates: Flavour Template support, including core components for single-page apps
  • widgets: Additional components for more specialized purposes
  • regex: Regular Expressions
  • routing: Path handling and view switching
  • json: Convert Java objects to and from browser JSON objects
  • rest: Wraps JAX-RS web services for seamless consumption from client-side Java code
  • archetype: A starter Flavour application for developers to begin new projects, showing many key features.
  • archetype-minimal: The most basic Flavour application showing only templates and the expression language. Doesn't include routing or other advanced features.

FAQ

Does Flavour support WASM?
At this time, Flavour compiles to JavaScript, for performance reasons. At present there is no user-driven motivation to switch to WASM — Flavour projects work great transpiled to JavaScript. However, TeaVM supports WASM, so it may be possible to switch to WASM in the future. If you try this out yourself, please post in the Flavour FOrums to let the community know how it worked.
